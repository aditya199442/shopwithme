# ShopNest Ecommerce Website — IT Fundamentals Project

ShopNest is a front-end ecommerce demonstration built with HTML, CSS and JavaScript.

## Features
- Responsive layout for desktop and mobile
- Electronics, Clothing, Shoes and Accessories categories
- Search products by name or category
- Add items to the shopping cart
- Increase/decrease quantities and remove products
- Automatic cart count and total in Indian rupees
- Demo checkout notice; no payments or personal data are collected

## Files
- `index.html` — website structure and content
- `style.css` — layout, colours and responsive styling
- `script.js` — product list, search, category filters and cart functions

## Run locally
Open `index.html` in a modern browser.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new public repository, e.g. `shopnest-ecommerce`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open repository **Settings** → **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for deployment and open the website URL shown on the Pages screen.

## Note
This is a student demo. It has no real account system, server database, payment gateway, or order processing. Do not enter real payment or private details.
